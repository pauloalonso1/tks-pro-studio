# TKS Pro Studio

Instalador do TKS Pro Studio para Windows 10 e 11 (64 bits). A versão mais recente fica em [Releases](https://github.com/pauloalonso1/tks-pro-studio/releases/latest).

Para usar, é preciso uma conta do TKS PRO com licença ativa. O passo a passo da instalação fica no painel do site: [www.tkspro.com.br](https://www.tkspro.com.br) → Início → TKS PRO Studio → Como instalar.
